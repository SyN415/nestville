# Nestville v2 — Walk Studio + Rename

## Rename
- Edit anytime from Profile
- 1–16 characters, trimmed
- HUD updates immediately
- Saved to localStorage `nestville_save_v1`

## Walk styles (any species)
- Species default
- Shell Rock, Waddle, Bounce Hop, Jiggle, Trot
- Toddle, Skip, Stomp, Sneak, March, Glide

Tune sliders: Speed, Bounce, Wobble, Squash, Spin (0.4–1.8 multipliers).

Body stays the species. Only motion changes.
