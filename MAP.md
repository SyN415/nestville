## Walk Studio Done
Style tiles preview only. They do not close the panel.

Footer:
`[Cancel]` … current style name … `[Done]`

- Done saves walkStyleId + walkTune and returns to the city
- Cancel restores the snapshot from when the studio opened
- Enter = Done, Esc = Cancel
- Same footer after birth so new creatures are not trapped in the picker

- Bench / stoop — sit, energy up
- Fountain — splash, cleanliness up
- Flowers — sniff, happy up
- Notice board — town tip
- Stick pile — start Fetch
- Doodle wall — sketch / recognize
- Lanterns — glow at dusk
- Bridge rail — look
